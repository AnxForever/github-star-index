## 当前限制

检索为词法召回，没有向量召回或模型重排；源码级别表示代表性路径阅读，不等于全仓审计或运行验证。卡片相对本地快照判断新鲜度，不自动确认 GitHub 最新版本。功能摘录匹配不能独立证明语义结论。

全自动模型分析、文件级增量重分析、可恢复后台任务、结构化兼容条件、托管账号和团队权限尚未实现。当前同步入口以 Stars 为主，不能宣称已覆盖所有用户自有仓库或任意代码来源。

## 发布边界

`release_bundle.py` 显式清单是公开源码范围。个人 catalog、快照、卡片、数据库、`INDEX.md`、截图、日志、凭据与本机授权说明均不发布；`.gitignore` 作为额外保护。第三方图标和字体按随附 ISC/OFL 许可分发；本项目 MIT 不覆盖被采集的第三方源码和文档。

早期本机 ZIP 是旧版中间产物，不代表此次 GitHub 提交。没有将本地网页部署为公网服务，也没有为本轮调用付费分析模型。
