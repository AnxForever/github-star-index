# 辅助界面设计

更新：2026-10-11。产品主要使用者是编码 AI。完整产品需求见 [REQUIREMENTS.md](REQUIREMENTS.md)，网页承担接入说明、索引状态与检索诊断。

## 视觉参考

用户指定当前使用的极简博客作为风格参考。沿用其黑白窄栏、细线、斜纹分区、Geist 字体和小型描边图标。此前误认的旧动漫博客不再作为参考。

- 颜色：白底 `#ffffff`、正文 `#18181b`、次级文字 `#71717a`、分隔线 `#e8e8ea`、浅灰 `#f6f6f7`；提供深色模式。
- 字体：本地 Geist Sans，中文使用系统黑体；工具调用使用系统等宽字体。
- 布局：768px 中央单栏，正文左对齐；手机保持单列。
- 动效：控件状态和按需打开的详情抽屉；遵循减少动效偏好。

调用过程是解释性的示意，不是已执行的 AI 会话。首页只读取本地索引状态，不列出全部收藏。网页不检测 MCP 客户端是否已连接；“索引可读”只描述 HTTP 服务读取数据库的结果。

## 辅助交互

- 检索诊断默认折叠，Ctrl/Cmd + K 打开并聚焦；Ctrl/Cmd + Enter 查询。
- 查询先显示三个候选，可继续展开；支持按类型、语言、归档状态和证据级别过滤。
- 候选显示用途、条件、限制与未知项；命中词不当作兼容性结论。
- 详情支持固定版本引用；对比和复制资料用于诊断、人工复核。
- 抽屉支持 Escape、焦点约束、返回触发位置和背景 inert。
- 首页不执行 AI 工作流、不调用模型；关闭网页不影响独立启动的 MCP 服务。
